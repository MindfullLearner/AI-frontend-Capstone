## Project

Frontend AI Engineering Capstone for the FlyRank AI Internship.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Git
- GitHub

## Coding Standards

- Write clean and readable code.
- Use meaningful variable and function names.
- Keep code simple and well organized.
- Add comments only when they improve understanding.
- Follow modern JavaScript best practices.

## Git Standards

- Follow Conventional Commits.
- Write clear commit messages.
- Keep commits focused on one change at a time.

## AI Assistant Guidelines

When helping with this project:

- Explain code before generating it.
- Recommend best practices.
- Avoid unnecessary libraries.
- Keep solutions beginner-friendly when possible.
- Help improve code quality and documentation.

## Project-Specific Development Rules

- Before implementing a feature, define its required fields, validation rules, expected behavior, and out-of-scope features. Do not add major functionality that is not part of the specification.

- Every interactive feature must be manually verified against both valid and invalid scenarios, including relevant edge cases and keyboard accessibility.

- Dynamic form controls must apply the same validation and accessibility requirements as the initial controls. Newly added options, criteria, or other inputs must not bypass validation.

- AI-generated code must be reviewed against the original specification after implementation. Do not assume that an AI-generated feature is complete merely because the AI reports success.

- When comparing alternative implementations, use actual code differences, test results, and review/fixing effort as evidence rather than relying only on subjective impressions.
